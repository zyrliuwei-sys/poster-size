# Poster Size page topology

1. **Edge navigation**
   - Sticky 48px bar with Poster Size wordmark, one primary browse action, saved link, and session action.
   - Interaction model: click-driven; mobile menu.
2. **Hero and specimen wall**
   - Two-column composition. The left side states the job; the right side shows three CSS poster specimens at different ratios.
   - Interaction model: static with hover movement on specimens.
3. **Catalogue finder**
   - Soft gray section with search, category tabs, result count, and a uniform grid of size cards.
   - Interaction model: click-driven filter/search and optimistic favourites.
4. **Reference notes**
   - Three short usage notes: print bleed, pixels versus physical dimensions, and selecting by ratio.
   - Interaction model: static.
5. **Statement footer**
   - Closing sentence, legal/account links, and ShipAny attribution on a single ruled line.
   - Interaction model: click-driven links only.

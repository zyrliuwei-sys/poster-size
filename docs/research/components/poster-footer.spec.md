# PosterFooter Specification

## Overview

- Target file: `src/components/poster-footer.tsx`
- Interaction model: static layout with link hover/focus states.
- Archetype: inline ruled footer with a short statement.

## Structure

- Large closing sentence on light paper.
- Rule-separated bottom row with account/legal links and `BuiltWithShipAny` attribution.
- No duplicated CTA intent and no decorative version labels.
